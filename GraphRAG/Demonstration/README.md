# GraphRAG Demonstrations

This package contains post-construction demonstration scenarios for the
connected FMEA graph and development-document graph.

## Scenarios

`reuse`
: Knowledge reuse for new product development. A new-product FMEA concern is
  used to retrieve similar historical failures and supporting development
  context.

`assistance`
: FMEA assistant for interpretation and review. Existing FMEA rows are
  interpreted together with linked document evidence so users or LLM-based
  tools can inspect rationale, review support, and check consistency.
